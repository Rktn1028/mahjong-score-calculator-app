# Mahjong Score Calculator App

翻と符を選ぶだけで、ロン・ツモの点数を計算するアプリです。

> 将来的には GitHub Pages をメインの公開リンクにする予定です。

## 使い方

1. 親・子を選びます。
2. ロン・ツモを選びます。
3. 符（20〜110符）と翻（1〜13翻以上）を選びます。
4. 点数がすぐに表示されます。

例：子・ロン・30符・3翻 → 3,900点

## できること

- ロン・ツモの点数を即座に計算
- 計算の内訳を表示（基本点 ＝ 符 × 2^(翻数＋2)）
- 点数早見表（1〜4翻、20〜110符）
- 満貫以上の早見表（満貫・跳満・倍満・三倍満・数え役満）
- 入力に合わせた早見表のハイライト（金のガイド線）
- スマートフォン対応
- 「入力Clear」ボタンで入力をすべてリセット

## 注意点

- 本場・供託（リーチ棒）は計算に含まれていません。
- 20符は平和ツモのみ、25符は七対子の符です。そのため、20符・25符のときは1翻を選べません。
- ロンのときは20符を選べません。

## 技術

- HTML / CSS / JavaScript のみで作られています。
- ビルドは不要です。`index.html` をブラウザで開くだけで動きます。
