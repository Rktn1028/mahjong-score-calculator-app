## 1. 概要

麻雀の点数を計算するアプリ。親／子、ロン／ツモ、符、翻を選ぶと、点数と計算の内訳を表示する。
あわせて、点数早見表（1〜4翻）と満貫以上の早見表を持ち、選択中の条件に該当する箇所をハイライトする。
本書はアプリ全体の現行仕様を扱う。

## 2. 用語

### 2.1 麻雀の用語

| 用語 | 意味 |
| --- | --- |
| 親 / 子 | あがった人の立場。親は点数が1.5倍になる |
| ロン / ツモ | ロンは他家の捨て牌であがること。ツモは自分のツモであがること |
| 符 | 手の構成で決まる点数の単位。20〜110符 |
| 翻 | 役の数。1〜13翻 |
| 基本点 | 符 × 2^(翻数＋2) で計算する、点数の元になる値 |
| 満貫 / 跳満 / 倍満 / 三倍満 / 数え役満 | 基本点が上限に達したときの役の段階。満貫は基本点2,000点相当 |

### 2.2 このアプリの用語（画面の部品）

| 用語 | 意味 |
| --- | --- |
| ヘッダー | 画面上部に固定された帯。「麻雀 点数計算」のタイトルと「入力Clear」ボタンを持つ |
| カード1（条件入力） | 親／子、ロン／ツモ、符、翻を選ぶエリア。PCでは画面左に縦いっぱいに配置 |
| カード2（計算結果） | 選んだ条件と計算結果の点数を表示するエリア。PCでは画面右上 |
| カード3（計算の内訳） | 基本点の計算過程を表示するエリア。PCでは画面右下 |
| カード4（点数早見表） | 1〜4翻・20〜110符の点数表。画面下部に全幅で配置 |
| カード5（満貫以上の早見表） | 満貫〜数え役満の点数表。画面最下部に全幅で配置 |
| フッター | 画面下部に常時表示される固定バー。「© 2026 R.KTN — Built with Muse」と表示 |
| 入力Clear | カード1の選択をすべて未選択に戻す操作。ヘッダーのボタンで行う |
| ハイライト | 結果に該当する早見表（1〜4翻はカード4、5翻以上はカード5）で、該当する行・列・セルを金色のガイド線で囲む表示 |
| 満貫切り上げ | 30符4翻・60符3翻を、満貫として扱うルール |
| 満貫切り上げスイッチ | 満貫切り上げをON／OFFする部品。カード2の右上に常時表示する。対象外のパターン（30符4翻・60符3翻以外）と入力が未完了のときはグレーアウトして押せない。ON／OFFの状態は保持され、入力Clearを押したときだけOFFに戻る |

## 3. 画面構成

- ヘッダー（固定表示）
  - タイトル「麻雀 点数計算」
  - 「入力Clear」ボタン（タイトルの右）
- カード1（条件入力）：親／子、ロン／ツモ、符、翻の選択ボタンを持つ
- カード2（計算結果）：条件の表示、点数、ツモ時の支払い内訳、満貫以上の役名を表示
- カード3（計算の内訳）：基本点の計算式と内訳を表示
- カード4（点数早見表）：1〜4翻、20〜110符
- カード5（満貫以上の早見表）：満貫、跳満、倍満、三倍満、数え役満
- フッター（画面下部に固定表示。スクロールしても常時表示される）
- スマートフォン（幅760px以下）では、カード1→2→3→4→5の順に縦に並ぶ

## 4. 入力の仕様

- 選べるもの:
  - 親／子（どちらか1つ）
  - ロン／ツモ（どちらか1つ）
  - 符：20、25、30、40、50、60、70、80、90、100、110
  - 翻：1〜13
- 入力の順番（ボタン制御、Issue #6）:
  - 親／子 → ロン／ツモ → 符 → 翻 の順にしか進めない。上の段を選ぶまで、下の段のボタンは押せない
  - 上の段の選択を変更しても、下の段の選択はリセットせず保持する（案A）
  - 押せるボタンと押せないボタンは、明暗と立体感の差で一目で判別できる見た目にする（ダークモードでも判別できること）。ロック中のボタン群は見出しも弱く表示する
  - どの段が押せるかは、現在の選択状態から一箇所で導出する
- 選べない組み合わせ（自動で制御される）:
  - 20符・25符のとき、1翻は選べない。20符・25符を選ぶと、1翻だった場合は2翻に自動で移る
  - ロンのとき、20符は選べない。ツモ20符の状態でロンに切り替えると、符は30符に自動で移る
  - 選べないボタンは押せない状態になり、ホバー時だけ理由のツールチップが出る
- 未選択の状態:
  - 4つの入力がすべてそろうまで、カード2・カード3は空で、カード4・カード5はハイライトしない
  - 初期表示は「入力Clear」を押した直後と同じ状態（すべて未選択で、親／子だけが押せる）
- 5翻以上のとき:
  - 符は選べるが、点数には影響しない

## 5. 計算ルール

| 条件 | 結果 |
| --- | --- |
| 基本点 | 符 × 2^(翻数＋2) |
| 子のロン | 基本点 × 4 を100点単位で切り上げ |
| 親のロン | 基本点 × 6 を100点単位で切り上げ |
| 子のツモ | 子から基本点 × 1、親から基本点 × 2（それぞれ100点単位で切り上げ） |
| 親のツモ | 全員から基本点 × 2（100点単位で切り上げ） |
| 基本点が2,000を超える場合 | 満貫として基本点2,000で固定する |
| 満貫切り上げON時 | 30符4翻・60符3翻（子の7,700点 / 親の11,600点）を満貫として扱う |

## 6. 表示の仕様

- カード2:
  - 左上に条件（例：親・ロン・30符・3翻）を小さく表示
  - 中央に符・翻と点数を表示。ツモの場合は受け取る合計点を表示
  - ツモのときは左下に支払いの内訳（子からいくら、親からいくら）を表示
  - 満貫以上のときは右下に役名を金色の明朝体で大きく表示
- カード3:
  - 「基本点 ＝ 符 × 2^(翻数＋2)」の式と、計算の内訳を表示
- カード4・カード5のハイライト:
  - ハイライトは「答えの居場所」だけに付ける。1〜4翻の結果（3・4翻の満貫を含む）はカード4のみ、5翻以上の結果はカード5のみがハイライトする（Issue #4で「両方ハイライト」を廃止）
  - 選択中の条件に該当する列（翻の見出しから該当行まで）と行（符の列から該当セルまで）を金色のガイド線でつなぎ、該当セルを四方で囲む
  - ハイライトされたセルでは、選択中のあがり方（ロン／ツモ）に該当する数字だけが濃く表示される
- カード4・カード5の表示/非表示:
  - ハイライト対象が確定している間（4つの入力がすべてそろい、計算結果が表示されている間）は、対象でない側の表を表示しない（Issue #5）
  - 対象がないとき（未入力・入力途中・入力Clear後）は、カード4・カード5の両方を表示する
  - 非表示の単位：PCではカードごと（対象でないカード全体を隠す）。スマホでは親/子の表ごと（対象でないカード全体を隠し、対象のカード内でも選択した親/子と一致しない側の表を隠す）
  - 表示/非表示の判定は、ハイライトの居場所と同じ導出から一箇所で行う
- 満貫切り上げON時のカード4:
  - 対象セルは数字ではなく「満貫」表記になる（ツモの支払い表記も満貫のものになる）
  - OFFのときや対象外のパターンでは、元の数字表記に戻る

## 7. 制約・例外

- 本場・供託（リーチ棒）は計算に含まれない
- 対象は4人麻雀のみ（3人麻雀には未対応）
- 役の判定はしない。符と翻は利用者が選ぶ
